# Поиск тендеров на Росэлторг (223-ФЗ)

Инструмент ищет закупки на `www.roseltorg.ru` по ключевым словам из ТЗ
(Screenshot_1.png) и выгружает Excel-отчёт с колонками **Название тендера**,
**Сумма**, **Дата окончания** (окончание приёма заявок).

> **Важно.** Запускать нужно на рабочей станции с доступом к `www.roseltorg.ru`.
> Из облака (Cursor Cloud) сайт недоступен, поэтому реальный поиск делается локально.

---

## Для сотрудника — запуск в один клик (Windows)

1. Один раз установите Python 3.10+ с [python.org](https://www.python.org/downloads/),
   при установке отметьте галочку **«Add Python to PATH»**.
2. Дважды кликните по **`run.bat`**.
   - При первом запуске окружение и браузер установятся автоматически (несколько минут).
   - Затем начнётся поиск; по завершении откроется файл **`report.xlsx`**.
3. Для приёмочной проверки (5 ключевых слов) — дважды кликните **`run_acceptance.bat`**
   и вручную сверьте название, сумму и дату окончания с карточками на сайте.

Готовый отчёт лежит рядом со скриптом: `report.xlsx`.

---

## Для разработчика — командная строка

```bash
pip install -r requirements.txt
python -m playwright install chromium

python -m roseltorg_tender_search run                 # полный поиск -> report с датой
python -m roseltorg_tender_search run -o report.xlsx  # свой путь к отчёту
python -m roseltorg_tender_search run --acceptance     # 5 разнотипных запросов
python -m roseltorg_tender_search run --show-browser   # видимое окно браузера
python -m roseltorg_tender_search run --dry-run        # только список запросов, без сайта
python -m roseltorg_tender_search keywords             # показать итоговые запросы
```

Тесты (без обращения к сайту):

```bash
pytest -q
```

## Как это работает

- `keywords.py` — строки словаря ровно со скриншота; строка с опечаткой
  «...кач**т**ства...» исключена.
- `search_rules.py` — разворачивает строки в запросы: `,` → отдельные запросы,
  `/` → альтернативы (в т.ч. с общим префиксом: «модернизация грп/грс»).
- `roseltorg_client.py` — Playwright открывает страницу поиска по 223-ФЗ,
  проходит пагинацию, извлекает название/сумму/дату окончания, убирает дубли.
- `excel_export.py` — сохраняет `.xlsx`.

## Если поиск не находит карточки

Росэлторг периодически меняет вёрстку. Селекторы вынесены в `config.py`
(`CARD_SELECTORS`, `TITLE_SELECTORS`, `AMOUNT_SELECTORS`, `DEADLINE_*`).
Откройте страницу поиска, через F12 найдите актуальные классы карточек и
поправьте значения — логика при этом не меняется.
