# Orchestrator

Отдельное Electron-приложение на базе Constructor. Функционал урезан по ТЗ 1.3 «Оркестратор должности»:

- шесть вкладок: Сегодня, Процессы, Решения, Показатели, История, Настройки
- два пилотных агента: ревизионная комиссия и подготовка совещания
- ручной запуск, пауза/возобновление
- встроенный чат и журнал заявок техподдержки
- диагностика администратора
- без конструктора агентов, регламентов и автозапуска

Цвет оболочки — синий.

Запуск:

```bat
desktop-electron\run_dev.bat
```

Нужен backend Constructor на `http://127.0.0.1:7812` для входа через 1С. Тестовый пользователь: Анна Де Армас.
